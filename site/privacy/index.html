Privacy policy

Last updated November 8, 2026.

The app

Fuginaut from the Mac App Store collects no data. It has no accounts, analytics, ads, or tracking, and it has no network access. Your settings stay on your Mac.

The Letters link beside a custom date pattern in the Format tab opens a Unicode page in your browser, where that site's own policy applies.

The Homebrew and download versions

These versions make no network requests and collect no data. Updates come through Homebrew, or from a new download that you choose to get.

This website

This site sets no cookies, runs no analytics, and loads nothing from other sites. Cloudflare hosts it and handles each request as any web host does. The Download button and the links to GitHub take you to GitHub, where its own policy applies.

Questions

Questions go to the issues page of the Fuginaut repository on GitHub.
