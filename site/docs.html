Getting started

Fuginaut runs on Apple silicon and Intel Macs with macOS 14 or later. It asks for no permissions and has no account.

  • Mac App Store: coming soon.
  • Homebrew: run brew install --cask dcadolph/tap/fuginaut.
  • Download: get the disk image, open it, and drag Fuginaut to Applications.

Open it and a clock appears at the center of the menu bar. There's no Dock icon and no window to manage. To open settings, click the clock or right-click the eclipse in the menu bar and pick Settings…. Every change shows in the live preview at the top of the window and on the real clock right away.

The eclipse icon

The eclipse in the menu bar is Fuginaut's icon. It glows amber while the clock is on and goes plain while it's off.

  • Click turns the clock on or off.
  • Right-click or Control-click opens the menu: Turn Clock Off or Turn Clock On, Settings…, and Quit Fuginaut.

If you hide the icon, open Fuginaut again from Applications to get back to settings, or click the clock if that's still on.

Color

Text color

Match the menu bar is on by default, which draws white on dark menu bars and black on light ones. Pick a color to turn it off. You can pick from a grid of 24 swatches, type a hex value, or use the color wheel.

Backing

A backing keeps the text readable over busy wallpaper. Style is None, Shadow, or Pill. Automatic color uses the opposite of the text color. Turn it off to pick a backing color the same three ways.

Custom patterns

Choose Custom pattern in the Style picker to write your own pattern using Unicode date letters. Put literal words in single quotes. Emoji work as typed. The menu beside the field holds ready examples and the common pattern letters, and the reset button returns to EEE d MMM HH:mm.

Second time zone

On the World tab, Time zone adds a second time beside the clock. Search the list by city, zone name, or UTC offset. Label sets the text beside that time, and it uses the zone's abbreviation if you leave it blank.

Displays and notches

Fuginaut draws a clock on every display you leave on. While an external display is connected, a laptop's own screen starts with the clock off, because the clock is meant for big screens. A laptop on its own shows the clock. A choice you make in General always wins.

On a screen with a notch, the clock slides beside the notch when it fits.

App Store and download versions

All the versions draw the same clock with the same settings. They differ in a few ways.

Mac App StoreHomebrew and download
UpdatesThe App Store handles them.Run brew upgrade --cask fuginaut, or download the new release.
NetworkNo network access.No network requests.
SandboxRuns in Apple's sandbox.Signed with a Developer ID and notarized by Apple.
Open at loginOff until you turn it on.Turns on the first time it runs from Applications.

Moving to the App Store version can carry over settings from a Homebrew or download install.

Reset and uninstall

Restore Defaults in General puts every setting back except Open at login. To uninstall, quit Fuginaut and delete it from Applications, or run brew uninstall --cask fuginaut if you installed it with Homebrew.
